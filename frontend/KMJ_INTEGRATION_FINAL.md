## 📊 Функциональность:

### Страница создания:
1. **Форма с полями:**
   - Пән атауы
   - Мұғалім аты-жөні
   - Сынып (1-12)
   - Сабақ нөмірі
   - Сабақ тақырыбы
   - Күні (определяет ценность)

2. **Автоматическая ценность:**
   - Выбираете дату → Система показывает ценность месяца
   - Отображается в красивом amber-блоке
   - Автоматически добавляется в AI промпт

3. **Выбор методов (макс 4):**
   - Карточки с именем и описанием
   - Клик → выбор (галочка появляется)
   - После 4-х остальные disabled
   - Счетчик "n/4 таңдалды"

4. **Генерация:**
   - Кнопка "ҚМЖ құру (5 токен)"
   - Создает план + запускает AI
   - Перенаправляет на страницу просмотра

### Страница просмотра:
1. **Статусы:**
   - `generating` → Индикатор AI с polling
   - `completed` → Показывает таблицу
   - `failed` → Ошибка с кнопкой повтора

2. **Таблица плана:**
   - Все ячейки: header, lesson_start, lesson_middle, lesson_end
   - Клик на ячейку → textarea для редактирования
   - Кнопки "Сақтау" / "Болдырмау"
   - Индикаторы: AI / Өңделген

3. **Действия:**
   - 🖨️ Басып шығару (печать)
   - ➕ Жаңа ҚМЖ құру (новый план)

## 🔧 API интеграция:

### Environment:
Использует `process.env.NEXT_PUBLIC_API_URL` для базового URL

### Endpoints:
```javascript
GET  /api/v1/teaching-methods          // Список методов
GET  /api/v1/national-values/month/:m  // Ценность месяца
POST /api/v1/kmj                        // Создание плана
POST /api/v1/kmj/:id/generate           // Запуск генерации
GET  /api/v1/kmj/:id                    // Получение плана
PUT  /api/v1/kmj/cells/:id              // Редактирование ячейки
```

## 📝 Пример использования:

### 1. Откройте материалы:
```
http://localhost:3000/kk/teacher/materials
```

### 2. Выберите "Қысқа мерзімді жоспар":
- Раньше была заглушка
- Теперь полная форма!

### 3. Заполните форму:
```
Пән: Информатика
Мұғалім: Ваше имя
Сынып: 8
Сабақ нөмірі: 16
Тақырып: Excel функцияларымен жұмыс
Күні: 15.09.2024  (← Показывает "Еңбекқорлық" ценность!)
```

### 4. Выберите методы:
```
☑️ Миға шабуыл
☑️ Джигсо
☑️ Фишбоун
☑️ Кластер
```

### 5. Нажмите "ҚМЖ құру":
- Переход на `/short-term-plan/:id`
- Статус "generating" → индикатор AI
- Автообновление каждые 3 сек
- Когда готово → показывает таблицу

### 6. Редактируйте:
- Клик на любую ячейку
- Меняйте текст
- "Сақтау"
- Помечается как "Өңделген"
