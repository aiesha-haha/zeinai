## 🎓 Как это работает:

### Шаг 1: Учитель создает план с методами

```json
POST /api/v1/kmj
{
  "subject": "Информатика",
  "grade": 8,
  "lesson_number": 16,
  "lesson_topic": "Excel функциялары",
  "teacher_name": "Арай Кенжебекова",
  "lesson_date": "2024-09-15T00:00:00Z",
  "content_lang": "kaz",
  "method_ids": [
    "uuid-brainstorming",
    "uuid-jigsaw",
    "uuid-fishbone",
    "uuid-cluster"
  ]
}
```

**Система автоматически:**
1. ✅ Определяет месяц (9 = Қыркүйек)
2. ✅ Находит ценность ("Еңбекқорлық және кәсіби біліктілік")
3. ✅ Сохраняет 4 выбранных метода
4. ✅ Создает пустую структуру клеток

### Шаг 2: Генерация с AI

```json
POST /api/v1/kmj/{id}/generate
```

**AI получает промпт:**

```
Сізге Қысқа мерзімді жоспар (ҚМЖ) құру керек.

Мәліметтер:
- Пән: Информатика
- Сынып: 8
- Сабақ нөмірі: 16
- Сабақ тақырыбы: Excel функциялары
- Мұғалім аты-жөні: Арай Кенжебекова

МАҢЫЗДЫ: Бұл сабақта "Қыркүйек" айының ұлттық құндылығын қолдануңыз.
Құндылық: Еңбекқорлық және кәсіби біліктілік
Сипаттама: Еңбексүйгіштік, кәсіби шеберлік пен дағдыларды дамыту

Сабақ тақырыбын осы құндылықпен біріктіріп, педагог пен оқушы әрекеттерінде 
практикалық қолдану мысалдарын көрсетіңіз.

ӘДІС-ТӘСІЛДЕР: Сабақты өткізу үшін міндетті түрде келесі әдістерді қолданыңыз:
1. Миға шабуыл - Қандай да болмасын ақпарат туралы бар білгендерін жазбаша немесе ауызша ой салу
2. Джигсо - Топ ішінде талқылап, әр түрлі тәсілдермен топтық жұмыс жасау
3. Фишбоун - Жаңа мәліметті, идеяларды сұрақ-жауап арқылы жинақтау
4. Кластер - Идеялар мен ақпараттардың арасындағы байланыстарды жинақтау

Әр әдісті сабақтың әртүрлі кезеңдерінде (басы, ортасы, соңы) қолданып, әрбір әдістің 
мақсатына сәйкес практикалық қолдануды көрсетіңіз. Әдістер тақырыппен табиғи түрде 
біріктірілуі керек.

Келесі құрылымда толық жоспар құрыңыз:
1. Шапка (header): Бөлім, педагог аты, күні, сынып, тақырып, мақсаттар
2. Сабақтың басы (10 мин): педагогтың әрекеті, оқушының әрекеті, бағалау, ресурстар
3. Сабақтың ортасы (30 мин): педагогтың әрекеті, оқушының әрекеті, бағалау, ресурстар
4. Сабақтың соңы (5 мин): педагогтың әрекеті, оқушының әрекеті, бағалау, ресурстар

Әр ұяшық бөлек қайтарылуы керек. JSON форматында қайтарыңыз.
```

- ✅ **Сабақтың соңы:** Кластер для рефлексии и обобщения
- ✅ **Ценность интегрирована:** Трудолюбие и профессионализм прослеживаются во всех этапах
