## 🎯 Тестирование:

### Шаг 1: Создание плана

1. Откройте http://localhost:3000/teacher/kmj/create
2. Заполните форму:
   - **Пән:** Информатика
   - **Мұғалім:** Ваше имя
   - **Сынып:** 8
   - **Сабақ нөмірі:** 16
   - **Тақырып:** Excel функцияларымен жұмыс
   - **Күні:** Выберите дату (месяц определит ценность)
3. Выберите до 4 методов (например: Миға шабуыл, Джигсо, Фишбоун, Кластер)
4. Нажмите **"ҚМЖ құру (5 токен)"**

### Шаг 2: Генерация

- Автоматически перенаправит на страницу плана
- Покажет индикатор генерации с AI
- Каждые 3 секунды проверяет статус
- Когда статус = "completed" → показывает таблицу

### Шаг 3: Просмотр и редактирование

- Клик на любую ячейку → текстовое поле
- Редактируйте содержимое
- Нажмите **"Сақтау"** чтобы сохранить
- Ячейка автоматически помечается как "Өңделген"

## 📝 Troubleshooting:

### Ошибка "Failed to fetch methods"
**Решение:**
1. Проверьте что backend запущен
2. Примените миграцию `012_teaching_methods.up.sql`
3. Добавьте методы в таблицу `teaching_methods`

### Ошибка "National value not found"
**Решение:**
1. Примените миграцию `011_national_values.up.sql`
2. Проверьте что данные добавлены в `national_values`

### Ошибка "Insufficient tokens"
**Решение:**
1. Увеличьте `tokens_limit` для пользователя
2. Уменьшите `tokens_used` до 0

### Генерация зависла
**Решение:**
1. Проверьте что RabbitMQ запущен
2. Проверьте что worker запущен
3. Проверьте логи backend
